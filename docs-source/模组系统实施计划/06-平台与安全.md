# 平台加载、安全与信任

> [返回统筹说明](./README.md)

## 9. 平台加载策略

| 平台 | 官方内容 | 第三方内容来源 | 持久化方式 |
| --- | --- | --- | --- |
| Web | 随 Web 构建发布 | 文件选择器导入 | IndexedDB |
| Electron | 随应用发布的只读副本 | 程序目录 `mods/` 或导入，构建时同步备份恢复 | 程序目录 `userdata/` 中保存全局启用状态、信任库和缓存 |
| Android | 随 APK 发布 | 不支持第三方数据包或后续模组 | 仅保留原版存档/设置所需的应用私有数据目录 |

Web/Electron 数据包解析和校验必须是平台无关的纯 TypeScript。文件系统、文件选择器和 IndexedDB 只作为 `ContentPackageSource` 适配器存在。Android 当前不提供第三方数据包来源适配器，只加载随 APK 发布的官方内容。

Electron 应继续保持 `nodeIntegration: false` 和 `contextIsolation: true`。主进程不得把任意路径读取、命令执行或 Node API 暴露给数据包。

### 9.1 版本目录隔离

Electron 的每个游戏版本可以放在独立目录中运行，并拥有完全独立的程序、官方内容包、`mods/`、`userdata/`、全局模组配置、发布者信任库、存档、缓存和日志：

```text
桃源乡-2.4.0/
  taoyuan.exe
  mods/
  userdata/

桃源乡-3.0.0/
  taoyuan.exe
  mods/
  userdata/
```

“模组全局启用”只表示在当前程序目录/安装实例内全局启用，不表示整台电脑上的所有版本共享配置。新版目录导入旧版存档时必须先复制，不能直接读写旧目录中的原文件。发布说明应建议玩家保留旧版本目录，直到确认新版副本可正常游玩。

Web 不能依靠可执行文件目录自然隔离，应为不同兼容环境使用独立存储命名空间或版本配置，并通过“复制后导入”进入新环境；不得让新版本直接覆盖尚未验证的旧环境存档。Android 只要求原版存档兼容和官方内容可游玩，不维护第三方模组环境。

### 9.2 资源类型与临时信任策略

当前计划临时取消第三方数据包可信度校验：Web/Electron 范围内发现或导入的任意第三方数据包默认视为可信，不再因为未签名、发布者未知、信任库缺失、密钥状态未知或玩家尚未确认发布者而被阻断。可信度临时放宽只改变“是否信任这个第三方数据包来源”的判断，不取消文件类型、路径、资源限制、Schema、依赖、语义、事务、存档环境和运行时发布门禁。

首版资源策略：

| 资源级别 | 示例 | 默认策略 |
| --- | --- | --- |
| 被动数据与文本 | JSON、纯文本、Markdown | 任意第三方数据包均按可信处理，仍需通过路径、大小、JSON、Schema 和语义校验 |
| 被动图像 | PNG、JPEG、WebP、GIF | 校验真实 MIME、尺寸和解码上限后允许 |
| 音视频 | OGG、MP3、WAV、WebM、MP4 | 校验真实 MIME、时长、码率和解码上限后允许 |
| 字体 | WOFF2 | 限制文件大小、字体数量和作用域后允许，不得安装到系统 |
| 可主动执行或嵌入脚本的资源 | SVG、HTML、脚本化媒体、Shader | 数据插件阶段仍默认拒绝；是否信任数据包不等同于允许嵌入脚本执行 |
| 可执行代码 | JS、MJS、CJS、WASM、Node 扩展、DLL、EXE、BAT、PowerShell | 当前第三方数据包阶段不开放代码执行；任意数据包可信不等同于事件/机制插件能力授权 |

签名、发布者信任库、密钥撤销列表和能力确认从当前第三方数据包加载前置条件中临时移除。仍保留规范化文件清单、每文件 SHA-256、`contentHash`、资源清单和完整性校验作为包身份、lockfile、缓存和诊断输入；签名系统后续重新启用时再恢复 Ed25519 发布者校验与撤销规则。

临时信任策略：

1. 官方内容包继续随游戏内置并作为官方基线处理。
2. 任意第三方数据包默认可信；发布者身份、签名状态、密钥撤销和玩家信任确认不作为加载阻断条件。
3. 未签名、签名缺失、签名不匹配或发布者未知只可作为诊断/展示信息，不得单独阻止数据包发现、安装、启用或运行时发布。
4. 路径越界、重解析点、资源限制、非法 MIME/资源类型、JSON/Schema/语义错误、依赖冲突、事务失败和存档环境不兼容仍然阻断候选环境。
5. 若后续重新启用可信度校验，必须把本节改回明确的发布者信任/签名门禁，并更新 lockfile、缓存环境哈希、错误码和迁移策略。

目录包还必须解析真实路径并拒绝通过 Windows junction、符号链接或其他重解析点越过包根目录。所有资源 URL 由挂载器生成，禁止数据包直接提供 `file:`、`javascript:` 或任意远程协议地址。
